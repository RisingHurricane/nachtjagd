# Multiplayer-Spiel

Kleines Echtzeit-Multiplayer-Spiel für die eigene Domain. Gebaut mit Node.js und WebSockets.

## Starten

```
npm install
npm start
```

Danach läuft das Spiel auf http://localhost:3000. Mit mehreren Browser-Fenstern lässt sich der Mehrspielerbetrieb ausprobieren. Gesteuert wird mit den Pfeiltasten oder mit WASD.

## Tests

```
npm test
```

## Zusammenarbeit mit KI-Agenten

Das Projekt wird abwechselnd mit Claude Code und Codex bearbeitet. Die Regeln dafür stehen in `AGENTS.md`, der aktuelle Arbeitsstand in `STATUS.md`.
